      True size

      The SVG is drawn in millimeters, so it imports at 1:1 in LightBurn, Glowforge, xTool Creative Space and Inkscape.

      One color per job

      Red is always the cut line. Pockets, glue guides and layer numbers each get their own color, so you can set them to score or engrave.

      Private by design

      Everything runs in your browser. Nothing is uploaded. Prefer the command line? Get the Python version on GitHub.
